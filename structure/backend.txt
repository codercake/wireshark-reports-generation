Express forwards the request to Flask, which starts the packet capture process

The packet capture service sends packets back to Express

Express stores the packets in MongoDB and broadcasts them to WebSocket clients

The data flow is: Wireshark (via pyshark) → Flask → Express → MongoDB + WebSocket clients


So the main components are:

1. Capturing packets via pyshark in the Python service.

2. Storing packets in MongoDB via Express.

3. Generating reports based on the stored packets.

 The generateWiresharkReport function should likely aggregate data from MongoDB, perform some analysis (maybe using the analyzer utilities mentioned), and then create a report file. The report could include traffic statistics, protocol distribution, security threats detected, etc.
